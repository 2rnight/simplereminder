预告条预览

这是真的 content.js 跑在假的 chrome API 上,不是截图。

预告条会从页面顶端滑下来,压在这个假网页最上方。它用的是原生 popover="manual" —— 非模态,所以页面仍然可以滚动、可以点、可以输入。

试这几件事:① 按空格 → 延迟(页面不会跟着滚一屏)。 ② 点预告条本身 → 同样是延迟。 ③ 把光标放进下面的输入框再打字 → 自动延迟,并且条上会告诉你它干了什么。

底边那条细线是剩余时间,和休息屏里的进度条是同一套语言: 递减表示剩余,不是递增表示已用。

连续点两次以上「延迟」,条上会出现 已延迟 ×2 角标 —— 第 1 次不显示,因为「×1」没有信息量。
